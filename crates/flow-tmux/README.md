# flow-tmux

Tmux session management for the [Agent Flow](https://github.com/aryayt/flow) workspace manager.

## Features

- Programmatic tmux session creation and management
- Window and pane operations for agent monitoring layouts
- Built on [tmux_interface](https://docs.rs/tmux_interface)

## Usage

```toml
[dependencies]
flow-tmux = "0.1.2"
```

```rust
use flow_tmux::session;
// Manage tmux sessions for agent workspaces
```
